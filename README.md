# 💼 Portfolio : Idir Sehrane, développeur web

Portfolio personnel d'**Idir Sehrane**, étudiant en BTS SIO option SLAM, réalisé pour présenter son parcours et ses projets (épreuve E5).

## 📌 Sections

| Section | Contenu |
|---|---|
| **À propos** | Présentation |
| **Compétences** | Langages et outils maîtrisés |
| **Parcours** | Formation et expériences |
| **Certifications** | Certifications, attestation PIX |
| **Projets** | Projets réalisés en BTS et en stage |
| **Veilles** | Veille technologique **GPU** et **Cloud** avec flux d'actualités chargés dynamiquement et bouton de rafraîchissement |
| **Contact** | Coordonnées |

Documents à télécharger dans `PDF/` : CV, certifications, PIX, tableau de synthèse E5, veilles technologiques.

## ✨ Points techniques

- Fond animé en `<canvas>`
- Menu responsive (burger) pour mobile
- Onglets de veille avec chargement asynchrone des articles (JavaScript)

## 🛠️ Technologies

HTML5 · CSS3 · JavaScript (vanilla)

## 🚀 Lancer le projet

Ouvrir `index.html` dans un navigateur, ou le publier avec **GitHub Pages** (*Settings → Pages → branche `main`*).
